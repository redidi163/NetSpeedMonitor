# native-13: 流量统计界面

**What to build:** 面板底部加一行当日合计，点这行弹出排行窗口（今日 / 近 7 天），只列前 10。

**Blocked by:** native-12

**Status:** todo

## 面板（280×348，尺寸不变）

- footer 上方加一行：`今日 ↓1.2 GB ↑340.5 MB`，右侧 `明细 ›`。
- 该行是点选区：命中则 `PostMessage` 到 host 打开排行窗口（与 `WM_APP+2` 同一套消息，落在 UI 线程）。
- 数字来自 `UsageLedger::TotalDown/TotalUp`；落盘失败时行尾加 `·` 并在 footer 提示未落盘。

## 排行窗口

- 320×420 DIP，`WS_POPUP | WS_EX_TOOLWINDOW`，无标题栏，自带关闭 ✕，可拖动（复用面板的拖动阈值 6 px）。
- 内容：标题「流量统计」+ 两个切换标签「今日 / 近 7 天」+ 10 行 `exe 名 / 条形 / 下载 / 上传`。
- 排序按 `down+up` 降序，单位 `GB`/`MB` 阈值同 `FormatBytes`。
- 数据全部来自账本（今日 = 当日行；近 7 天 = 最近 7 个日期行求和），界面不做二次聚合。
- 不属于前台窗口、不抢焦点；点窗口外收起（与面板同一套 `WH_MOUSE_LL` + 前台轮询，抽成共用实现，不复制一份）。

## 判定依据

| # | 判据 | 方法 |
|---|---|---|
| 1 | 界面数字 = 文件聚合值 | 直接解析当月 TSV 求和，与窗口逐行对比，10 行全等 |
| 2 | 排序正确 | 构造两组数据，第二组更大时上下顺序互换 |
| 3 | 点面板外收起排行窗口 | 与 native-10 判据同法，≤250 ms |
| 4 | 窗口不抢焦点 | 打开前后 `GetForegroundWindow()` 不变 |
| 5 | 面板尺寸不变 | 窗口矩形仍是 280×348 DIP（144 dpi 下 420×522 px） |
