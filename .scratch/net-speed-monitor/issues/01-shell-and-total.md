# 01: 骨架 + 总量显示

**What to build:** 用户双击 exe 后，托盘出现图标，桌面出现一个 280×200 无边框置顶小窗。窗口每秒刷新当前默认路由网卡的下载/上传速率：大字 MB/s、小字 Mbps，下行/上行双行，底部一条 60 秒迷你走势。点 X 隐藏到托盘，托盘单击切换显示/隐藏。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 启动后出现托盘图标与置顶小窗，窗口可拖动，关闭按钮隐藏而非退出
- [ ] 与任务管理器「性能 → WLAN」对照，空闲和下载两种状态下总量误差 <10%
- [ ] 60 秒走势条随时间推进，数据不足 60 秒时不出现跳变
- [ ] 默认路由接口被自动选中（本机为 WLAN 2），不统计 Hyper-V 虚拟网卡
