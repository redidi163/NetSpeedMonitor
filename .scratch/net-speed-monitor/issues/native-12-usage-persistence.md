# native-12: 流量累计持久化（按天）

**What to build:** 把 native-11 的内存账本按天落到磁盘，启动时读回当日与近 7 天，跨天自动换行，90 天后滚动删除。

**Blocked by:** native-11

**Status:** todo

## 文件格式

`%LOCALAPPDATA%\NetSpeedMonitor\usage\YYYY-MM.tsv`，按月一个文件、UTF-8、Tab 分隔：

```
date	exe	downBytes	upBytes	lastSeenUnix
2026-11-19	msedge.exe	123456789	9876543	1763550000
```

- 只追加当日行、重写时整文件原子替换（临时文件 + `MoveFileExW(MOVEFILE_REPLACE_EXISTING)`）。
- 写盘节流：内存累加，距上次落盘 ≥30 s 或增量 >1 MB 才写；退出（`WM_DESTROY`）强制 flush。
- 崩溃最多丢 30 s，不做 WAL。

## 需要处理的边界

- 跨 00:00：新日期开新行，旧行数值冻结。
- 时钟回拨：日期倒退时不删已有行，只累加到较早那天；同一 `date+exe` 行唯一。
- 文件损坏/截断：跳过无法解析的行并继续加载，不崩溃、不写负数。
- 加载失败（权限、磁盘满）：内存账本照常工作，UI 标注「未落盘」。
- 90 天滚动：删除早于 90 天的行，空月份文件直接删。
- 进程名含 Tab 或换行：写入前替换为空格（exe 名理论上不含，防御性处理）。

## 判定依据

| # | 判据 | 方法 |
|---|---|---|
| 1 | 重启后当日值不减 | 记录前值 → 结束进程 → 重启 → 读回值 ≥ 前值 |
| 2 | 跨天换行 | 伪造系统日期或用测试注入当前日期，出现新行且旧行不变 |
| 3 | 损坏容错 | 截断文件末尾 20 字节，加载后不崩溃、无负数 |
| 4 | 原子写 | 写盘过程中断电模拟（强杀进程）后文件仍可解析 |
| 5 | 滚动 | 注入 91 天前的行，加载后被删除 |
